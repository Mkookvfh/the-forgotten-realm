# THE FORGOTTEN REALM — Update 0.12 (พันธะเลือด · คอมโบดูดเลือด)

เกม 3D Dark Fantasy มุมมอง Third Person สำหรับเว็บและ Android (ต้นแบบที่เล่นได้)

## ใหม่ใน Update 0.12
- **พันธะเลือด (Blood Pact)**: ตีอาวุธต่อเนื่องภายใน 2.8 วินาทีเพื่อสะสมคอมโบสูงสุด 20 ระดับ
- **5/10/15 คอมโบ**: ดาเมจเพิ่ม +8% / +18% / +30% และทุกครั้งที่โจมตีจะดูดเลือดคืน +1 / +2 / +3 HP ตามขั้น
- **การ์ดคอมโบ**: เลขคอมโบ, ชื่อขั้น (ไหลเวียน/คลั่ง/กระหายเลือด), แถบเวลาถอยหลัง และโบนัสดาเมจ/ดูดเลือด — พร้อมสีประจำขั้นและเสียงใหม่
- **ตัวเลขลอย +1/+2/+3** เหนือหัวเมื่อดูดเลือด และข้อความ "พันธะเลือด!" เมื่อข้ามขั้น
- **สถิติคอมโบสูงสุด** บันทึกในเซฟ พร้อมคำอธิบายระบบในกระเป๋า
- คอมโบดับเมื่อหยุดตี 2.8 วินาที, ล้มสลบ, เดินทางเร็ว หรือโหลดเซฟ
- Save v10 โหลดเซฟ v7–v9 เดิมได้
- รายละเอียดทั้งหมดอยู่ใน [CHANGELOG_0.12.md](CHANGELOG_0.12.md)

## ระบบที่รวมอยู่
- ฉากป่ามืด ภูเขา แม่น้ำ ซากโบราณ หอคอย ถ้ำต้องสาป หมอก แสงกลางวัน/กลางคืน และฝน
- แสงเงา หิ่งห้อย เอฟเฟกต์เวท, LOD สำหรับต้นไม้/หิน/ศัตรู, ลดจำนวนหญ้าตามคุณภาพ และจำกัด FPS ได้
- ตัวละคร Sprite 4 ทิศทาง พร้อมแอนิเมชันเดิน วิ่ง หลบหลีก โจมตี และรับความเสียหาย
- เดิน วิ่ง กระโดด หลบหลีก พร้อมกล้องติดตาม ปรับมุมและระยะกล้องได้
- ระบบต่อสู้ ศัตรู AI หลายเฟส บอส 2 ตัว และสัตว์ป่า (กวางวิญญาณ/หมาป่ามืด)
- ระบบพันธะเลือด: คอมโบจากการตีต่อเนื่อง เพิ่มดาเมจและดูดเลือดคืนตามขั้น 5/10/15 พร้อมสถิติคอมโบสูงสุด
- ระบบอาวุธ 7 แบบ: ดาบ ดาบใหญ่ ขวาน คทาเวท ธนูพรานป่า (ยิงลูกธนู) คทาเหมันต์ (ยิงน้ำแข็งและทำให้ศัตรูช้าลง) และดาบเงาว่าง (ตำนาน)
- ระบบเกราะ 6 แบบ: หนัง เหล็ก เกราะพราน ผ้าคลุมรูน เงา และเกราะมังกรร้าง (ตำนาน)
- สายอาชีพ 3 สาย เลือกได้จากกระเป๋า: นักรบ (โจมตีระยะประชิดแรงขึ้น ลดความเสียหาย) พราน (โจมตีระยะไกลแรงขึ้น ฟื้นพละกำลังเร็ว) จอมเวท (พลังเวทแรงขึ้น ฟื้นมนตราเร็ว)
- ระบบตั้งแคมป์ (G): กองไฟเป็นจุดเกิดใหม่ พักผ่อนจนรุ่งเช้าเพื่อฟื้น HP/STA/MP และปรุงอาหารจากเนื้อสด+สมุนไพรเป็นยาฟื้นฟู (ตั้งแคมป์/พักไม่ได้เมื่อมีศัตรูใกล้หรืออยู่ในถ้ำ)
- เวทมนตร์ 2 แบบ: ลูกไฟและการรักษา พร้อมแต้มทักษะ 3 สาย
- ระบบคราฟต์ ดรอปตามความหายาก วัตถุดิบ และร้านค้าซื้อ/ขายของด้วยทอง
- ระบบอัปเกรดอุปกรณ์ +0 ถึง +5 ต่อชิ้น (ทอง + แร่ + ผลึก) พร้อมแสดงพลังโจมตี/ป้องกันที่เพิ่มขึ้น
- กระดานสัญญาล่าค่าหัวแบบวนซ้ำ 3 ใบ พร้อมรางวัลทอง/XP/วัตถุดิบ และปุ่มรับสัญญาชุดใหม่
- NPC เดินตามตารางเวลา 3 คน: นักพรต ช่างตีเหล็ก และพ่อค้าเร่ร่อน
- ภารกิจหลัก ภารกิจรอบ และพื้นที่ที่ค้นพบได้ 6 เขต พร้อมมินิแมพและแผนที่โลก
- ดันเจี้ยนถ้ำต้องสาป 4 คลื่นศัตรูและบอสประจำถ้ำ เมื่อผ่านจะได้รางวัลพิเศษ
- ระบบเสียงบรรยากาศและเอฟเฟกต์ที่สร้างจาก WebAudio ไม่ต้องใช้ไฟล์เสียงภายนอก
- บันทึก/โหลด 3 ช่อง พร้อมบันทึกอัตโนมัติทุก 30 วินาที
- ปุ่มควบคุมสัมผัสสำหรับมือถือ (จอยซ้าย + ปุ่มวงกลมขวา) และคีย์บอร์ด/เมาส์สำหรับคอมพิวเตอร์
- GitHub Actions สำหรับ Deploy เว็บ และ Build Android Release APK ผ่านคลาวด์

## ข้อจำกัดที่ควรทราบ
โปรเจกต์นี้ยังเป็นต้นแบบ ไม่ใช่เกม Open World เต็มรูปแบบหรือเกมระดับผลิตจริง
- โมเดลตัวละคร ศัตรู อาวุธ และเกราะยังใช้รูปทรง Three.js พื้นฐาน
- ยังไม่มีระบบ Multiplayer หรือเซิร์ฟเวอร์ร่วมเล่น
- ยังไม่มีแอนิเมชันต่อสู้แบบโมเดลกระดูก ( skeletal animation )
- Android workflow เซ็น Release APK ด้วย debug key สำหรับติดตั้งทดสอบในเครื่อง ไม่ใช่ signing key สำหรับ Play Store
- แผนที่ GLB จะโหลดก็ต่อเมื่อเปิดเว็บด้วย `?glb` และมีไฟล์ `public/assets/world/open-world-dark-fantasy.glb` มิเช่นนั้นจะใช้ฉากต้นแบบ

## ทดสอบเว็บ
```bash
npm install
npm run dev
```
เปิด URL ที่ Vite แสดง

สร้างไฟล์เว็บ:
```bash
npm run build
```

สร้าง Android Release APK สำหรับติดตั้งในเครื่อง:
```bash
npm run android:release
```
ไฟล์จะอยู่ที่ `android/app/build/outputs/apk/release/app-release.apk` คำสั่งนี้ต้องมี JDK 17 และ Android SDK ที่ตั้งค่า `ANDROID_HOME`/`ANDROID_SDK_ROOT` แล้ว รุ่น Release ในโปรเจกต์เซ็นด้วย debug key เพื่อการติดตั้งทดสอบในเครื่อง

## สร้าง Android Release APK จาก GitHub
1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน repository โดยให้ `package.json` อยู่ที่ root
2. Commit และ push ไปยัง branch `main`
3. เปิดแท็บ **Actions**
4. เลือก **Build Android APK**
5. กด **Run workflow** หรือรอให้ workflow ทำงานหลัง push
6. เปิด workflow run ที่เสร็จแล้วดาวน์โหลด artifact `the-forgotten-realm-release-apk`
7. แตกไฟล์ artifact แล้วติดตั้ง `app-release.apk`

## หมายเหตุสำคัญ
- อย่าลบไฟล์ `src/` หรือ `.github/workflows/`
- บันทึกเกมเวอร์ชันเก่ายังโหลดได้ที่ช่อง 1 และจะได้รับทองเริ่มต้น 60
- ระบบ NPC และสัตว์ป่าจะกลับไปตำแหน่งเริ่มต้นหลังโหลดเกม
- APK ที่ได้จาก workflow เป็น Release variant ที่เซ็นด้วย debug key สำหรับติดตั้งในเครื่อง ไม่ใช่ไฟล์สำหรับอัปโหลด Play Store
