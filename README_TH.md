# THE FORGOTTEN REALM — Complete Update 0.4

เกม 3D Dark Fantasy มุมมอง Third Person สำหรับเว็บและ Android (ต้นแบบที่เล่นได้)

## ระบบที่รวมอยู่
- ฉากป่ามืด ภูเขา แม่น้ำ ซากโบราณ หอคอย หมอก แสงกลางวัน/กลางคืน และฝน
- แสงเงาและหิ่งห้อย พร้อมการปรับคุณภาพกราฟิกให้เหมาะกับมือถือ
- ตัวละครต้นแบบ 3D พร้อมกล้องติดตาม
- เดิน วิ่ง กระโดด และหลบหลีก
- ระบบต่อสู้ ศัตรู AI ไล่ตาม โจมตี และแถบ HP ศัตรู
- ระบบอาวุธ 3 แบบ: ดาบ ดาบใหญ่ และคทาเวท (คทาใช้ระยะโจมตีที่ไกลขึ้น ยังไม่มีเอฟเฟกต์เวท/กระสุน)
- ระบบเกราะ 3 แบบ: หนัง เหล็ก และเงา ลดความเสียหายตามชนิดเกราะ
- ระบบเลเวล EXP และแต้มทักษะ เพิ่มพลังโจมตี
- ผลึกเก็บสะสม ยาฟื้นฟู ภารกิจ และการค้นพบพื้นที่
- บันทึก/โหลดเกมผ่าน localStorage และบันทึกอัตโนมัติ
- ปุ่มควบคุมสัมผัสสำหรับมือถือ และคีย์บอร์ด/เมาส์สำหรับคอมพิวเตอร์
- ปรับขนาดหน้าจอและการหมุนจอ
- GitHub Actions สำหรับ Deploy เว็บ และ Build Android Debug APK ผ่านคลาวด์

## ข้อจำกัดที่ควรทราบ
โปรเจกต์นี้ยังเป็นต้นแบบ ไม่ใช่เกม Open World เต็มรูปแบบหรือเกมระดับผลิตจริง
- โมเดลตัวละคร ศัตรู อาวุธ และเกราะยังเป็นรูปทรง Three.js พื้นฐาน
- ยังไม่มีแอนิเมชันต่อสู้เฉพาะอาวุธ เอฟเฟกต์กระสุนเวท หรือระบบปลดล็อกอุปกรณ์
- ระบบเกราะ/อาวุธเลือกได้จากกระเป๋าอุปกรณ์เพื่อทดสอบ
- Android workflow สร้าง Debug APK สำหรับทดสอบ ไม่ใช่ไฟล์ลง Play Store
- ยังต้องทดสอบบนอุปกรณ์จริงหลายรุ่นก่อนเผยแพร่

## ทดสอบเว็บ
```bash
npm install
npm run dev
```
เปิด URL ที่ Vite แสดง

สร้างไฟล์เว็บ:
```bash
npm run build
```

## สร้าง Android Debug APK จาก GitHub (ทำได้ผ่านมือถือ)
1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้เข้า repository โดยให้ `package.json` อยู่ที่ root
2. Commit และ push ไปยัง branch `main`
3. เปิดแท็บ **Actions**
4. เลือก **Build Android APK**
5. กด **Run workflow** หรือรอให้ workflow ทำงานหลัง push
6. เปิด workflow run ที่เสร็จแล้วดาวน์โหลด artifact `the-forgotten-realm-debug-apk`
7. แตกไฟล์ artifact แล้วติดตั้ง `app-debug.apk` เพื่อทดสอบ

## หมายเหตุสำคัญ
- อย่าลบไฟล์ `src/` หรือ `.github/workflows/`
- หากนำ ZIP นี้ไปใช้แทนโปรเจกต์เดิม ให้สำรอง repository เดิมก่อน
- บันทึกเกมเก่ารองรับการโหลด: อาวุธและเกราะจะเริ่มต้นเป็นดาบ/เกราะหนัง และแต้มทักษะเริ่มที่ 0
- APK ที่ได้จาก workflow เป็น Debug APK เท่านั้น ยังไม่ใช่ Signed Release APK สำหรับ Play Store
